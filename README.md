# Apple Music Lakehouse Pipeline on Azure

> **Learning project:** Hands-on Azure data engineering practice project built by [Prakash Kantumutchu (KP)](https://thisiskp.in) to explore watermark-based incremental ingestion in Azure Data Factory, medallion storage on Azure Data Lake Storage Gen2, and Databricks transformation notebooks.

---

## Overview

This repository contains the Azure Data Factory (ADF) definitions, SQL setup scripts, and Databricks notebook archive (`dab.dbc`) for an Apple Music streaming analytics pipeline following a Bronze / Silver / Gold medallion design:

1. **Incremental ingestion (Azure Data Factory):**
   - `pipeline/Incremental_ingestion.json` reads a high-water mark (`cdc.json`), queries new/updated rows from Azure SQL Database, writes Parquet files to ADLS Gen2, and updates the watermark only when new rows are copied.
   - `pipeline/incremental_loop.json` wraps the incremental copy pattern in a metadata-driven `ForEach` loop (`loop_input`) across multiple source tables, with a failure alert webhook activity.
2. **Transformation (Azure Databricks):**
   - `dab.dbc` contains the Databricks notebook archive used to read Bronze Parquet files from ADLS Gen2 and transform them into Silver and Gold Delta tables.
3. **ARM templates:**
   - `adf-musicdataproject/` holds the exported Azure Resource Manager templates and parameter files generated by ADF Git integration.
